This is Pokeclicker for Archipelago. It is not a standalone game and must be connected to an AP server to make progress.

The web client is located at:
https://hallstead.github.io/AP-Pokeclicker/

The desktop client is located at:
https://github.com/Hallstead/Pokeclicker-desktop/releases/latest

To connect to the server:
- Enter your host address, port, and slot name (and password if you have one).
- Then click the "Connect (Archipelago)" button.
